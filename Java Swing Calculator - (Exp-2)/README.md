# Java Swing Calculator

## Description
A desktop calculator application developed using Java Swing. It demonstrates GUI development and the separation of application logic from the user interface.

## Technologies Used
- Java
- Java Swing
- AWT

## Requirements
- JDK
- VS Code or IntelliJ IDEA

## How to Run
1. Open the calculator project folder.
2. Compile the Java files:
   ```bash
   javac *.java
   ```
3. Run the main class:
   ```bash
   java Main
   ```

## Learning Outcome
Understand GUI components, event handling, and basic calculator operations in Java.
