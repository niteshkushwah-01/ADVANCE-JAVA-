# Java Remote Method Invocation (RMI)

## Description
This practical demonstrates Java RMI, which allows a Java program to call methods on an object running in another Java process.

## Technologies Used
- Java
- Java RMI

## Requirements
- JDK
- VS Code or IntelliJ IDEA

## How to Run
1. Open the RMI project folder.
2. Compile the Java files:
   ```bash
   javac *.java
   ```
3. Start the RMI server:
   ```bash
   java Server
   ```
4. Open another terminal and run:
   ```bash
   java Client
   ```

Follow any registry setup required by the source code.

## Learning Outcome
Understand remote method calls and distributed Java applications.
