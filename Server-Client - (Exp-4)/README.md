# Java Client–Server Programming

## Description
This practical demonstrates communication between a client and a server using Java networking.

## Technologies Used
- Java
- Socket Programming

## Requirements
- JDK
- VS Code or IntelliJ IDEA

## How to Run
1. Open the project folder.
2. Compile the Java files:
   ```bash
   javac *.java
   ```
3. Start the server:
   ```bash
   java Server
   ```
4. Open another terminal and run:
   ```bash
   java Client
   ```

## Learning Outcome
Understand client–server communication using Java sockets.
