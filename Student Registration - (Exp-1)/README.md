# Student Registration System

## Description
A Java application that demonstrates student registration. It includes a basic Java version and a JDBC-based version connected to a MySQL database.

## Technologies Used
- Java
- JDBC
- MySQL

## Requirements
- JDK installed
- MySQL Server for the database version
- MySQL Connector/J

## How to Run
1. Open the project folder in VS Code or IntelliJ.
2. Compile the Java file:
   ```bash
   javac StudentRegistration.java
   ```
3. Run the program:
   ```bash
   java StudentRegistration
   ```

For the database version, execute the SQL script and configure the database connection before running.

## Learning Outcome
Learn basic Java programming and database connectivity using JDBC.
